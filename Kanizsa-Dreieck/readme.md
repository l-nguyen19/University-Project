# Kanizsa-Dreieck

**Hinweis:** Letzte Bearbeitung 14.02.2023

## Voraussetzungen

Für die Nutzung wird **Jupyter Notebook** benötigt.

## Verwendung

Öffnen Sie die Datei `Kanizsa_triangle.ipynb` mit Jupyter Notebook. Das Programm ist in mehrere Abschnitte unterteilt, die jeweils durch das Ausführen der entsprechenden Zellen gestartet werden können.

### 1. Klassisches Kanizsa-Dreieck

Durch das Ausführen der ersten Zelle wird das klassische **Kanizsa-Dreieck** dargestellt.

### 2. Kanizsa-Effekt mit beliebigem Winkel

Die zweite Zelle ermöglicht die Darstellung des Kanizsa-Effekts mit einem frei wählbaren Winkel.

Nach dem Start der Zelle fordert das Programm den Benutzer auf, einen Winkel in Grad einzugeben. Nach der Eingabe und dem Drücken der **Enter-Taste** wird der Kanizsa-Effekt mit dem angegebenen Winkel dargestellt.

### 3. Kanizsa-Effekt mit frei wählbaren Kreispositionen

Durch das Ausführen der dritten Zelle kann der Kanizsa-Effekt mit frei wählbaren Positionen der Kreise dargestellt werden.

Das Programm fragt nacheinander nach den Koordinaten der Mittelpunkte der Kreise. Nachdem alle Koordinaten eingegeben wurden, wird der Effekt entsprechend der angegebenen Positionen geplottet.

### 4. Weitere Beispiele

Die verbleibenden Zellen enthalten Beispiele für verschiedene Dreiecksformen. Diese können ebenfalls durch das Ausführen der jeweiligen Zelle dargestellt werden.
